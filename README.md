# Medical Insurance Cost Prediction using Linear Regression

## Project Overview
This project focuses on predicting medical insurance costs using a Linear Regression model in Python. The dataset used contains information about individuals such as age, BMI, smoking status, and more.

The goal is to understand how different factors influence insurance charges and build a model to predict these costs.

---

## Dataset Information
The dataset used is the Medical Insurance Dataset from Kaggle.

### Features:
- age: Age of the individual
- sex: Gender
- bmi: Body Mass Index
- children: Number of dependents
- smoker: Smoking status
- region: Residential area
- charges: Medical insurance cost (Target Variable)
